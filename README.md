## 清理规则

任务涉及生成、下载、安装、构建、脚本、日志或临时产物时，结束前检查本任务相关位置。只删除本次产生且不再需要的辅助文件，保留原始输入、源码、配置、证据、最终成果、持久缓存和已安装技能/插件。
